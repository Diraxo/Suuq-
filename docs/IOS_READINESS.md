## What was implemented
| Area | Change |
|---|---|
| Sign in with Apple | `expo-apple-authentication` + `expo-crypto` (SDK 57 pins). `store/auth.ts: signInWithApple` → native Apple sheet (nonce: SHA-256 to Apple, raw to Supabase) → `supabase.auth.signInWithIdToken({provider:'apple'})`. Same Supabase `auth.users`/`profiles` as Google; existing `on_auth_user_created` trigger creates the profile. First-auth name saved only into an empty `profiles.full_name`. Cancel (`ERR_REQUEST_CANCELED`) is silent. Native `AppleAuthenticationButton` (`components/AppleSignInButton.tsx`, iOS only, black/white by theme, pill radius like the Google button) added under Google in `AuthPromptModal` (Favorite/Sell/Profile prompts) and the guest Profile screen. Google flow and Android untouched. |
| Config | `app.json`: `ios.usesAppleSignIn`, `expo-apple-authentication` plugin, `aps-environment` entitlement (iOS only), `ITSAppUsesNonExemptEncryption:false` (**owner to confirm**). |
| Launch screen | `assets/images/suuqiye-launch-ios.png` (generated by `scripts/build-suuqiye-ios-launch.py` from the real icon fonts + existing logo, same geometry as `app/index.tsx`) used via the splash plugin's `ios` override only. Android splash config unchanged. In-app splash on iOS now starts with icons already visible (no vanish/reappear); glow, name, tagline still animate, so it's a continuation, not a duplicate. |
| Account deletion | Existing in-app deletion + edge function kept. Added Apple token revocation (Apple requirement): iOS re-prompts Apple for an `authorizationCode`; `delete-account` exchanges/revokes it when Apple secrets are set; otherwise skipped and deletion proceeds. |

## Owner actions
1. Apple Developer: App ID `suuqiye.com` → enable **Sign in with Apple** and **Push Notifications** (EAS can sync these).
2. Supabase Dashboard → Auth → Providers → **Apple**: enable, set Client IDs = `suuqiye.com` (native flow needs no secret). Account linking: Supabase links identities with the same verified email; Apple "Hide My Email" users will be separate accounts from their Google account — a design decision to accept.
3. Deploy `delete-account`; set secrets `APPLE_TEAM_ID`, `APPLE_KEY_ID`, `APPLE_CLIENT_ID=suuqiye.com`, `APPLE_PRIVATE_KEY` (a Sign in with Apple .p8 key).
4. Publish `docs/` (git push) so the live legal pages include the Apple changes; have legal review them.
5. `eas build -p ios --profile production` (and a development build first); test on a physical iPhone: Apple sign-in (first + repeat + cancel), push receipt/tap, delete account with a test account, launch screen cold/warm.
6.
